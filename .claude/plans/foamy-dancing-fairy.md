# VO 主导模式分镜提示词测试与优化计划

## Context

用户要求测试 VO 主导模式下的分镜生成，使用测试文本：
> "我穿成传国玉玺三百年，连系统都不甘寂寞的跑了。我见证了大梁、大周、大陈三个皇朝的兴衰。受命于天，既寿永昌。大梁末帝在宫城大火中将我扔出宫墙，不愿我成亡国之玺"

## 问题分析（已确认）

### 当前代码结构

在 `application/services/storyboard_service.go` 中：

| 位置 | 内容 | 问题 |
|-----|------|------|
| 第143-162行 | **VO 铁则**："一整段连续旁白 → 不切碎成大量分镜" | ✅ 正确 |
| 第196行 | `modeSpecificPrompt` 插入位置 | ⚠️ 在中间 |
| 第321-331行 | **特别要求**："逐句逐段转换为分镜" | ❌ 与 VO 铁则冲突 |
| 第323行后 | 提示词结束 | ⚠️ VO 铁则不在最后 |

### 核心冲突

```
提示词顺序：
  1. 系统提示词
  2. 分镜要素说明
  3. 输出格式
  4. ...
  5. 【modeSpecificPrompt】← VO铁则在这里（第196行）
  6. ...
  7. 【特别要求】← "逐句逐段"在这里（第321行）⚠️
  8. 【禁止行为】
  9. 描述原则
```

**问题**：LLM 通常更重视后面出现的指令 → "逐句逐段"会压倒"不切碎"

## 实施方案

### 第一步：测试当前实现（验证问题）

创建测试脚本，生成完整提示词并检查。

### 第二步：修复提示词

#### 修改 A：调整 VO 模式的提示词结构

在 VO 主导模式下：
1. **保留** VO 铁则 4 条
2. **添加** 优先级说明（VO 铁则优先）
3. **添加** 合理拆分规则（适配视频时长限制）
4. **修改** "特别要求"部分（VO 模式下弱化逐句逐段）
5. **将 VO 模式特定内容移到提示词最后**

#### 修改 B：增强的 VO 模式提示词

```
【VO短剧·分镜铁则（强制遵守）】
1. 旁白存在 → 人物只做轻微动作/状态，禁止开口说话、无台词、无对话
2. 只有出现「角色台词/对话」→ 旁白立刻停止，进入表演模式
3. 旁白段落可配：镜头运动、环境音、BGM、人物微动，画面允许动态
4. 一整段连续旁白 → 不切碎成大量分镜，保证旁白流畅

【dialogue 字段标注格式】
- 旁白内容格式：【旁白段】历史的车轮继续向前...
- 对话内容格式：【对话段】梁末帝说:"我不需要你来背负这个责任..."
- 一个镜头中，【旁白段】和【对话段】不能同时出现，必须二选一

【人物行为】
- 【旁白模式】：只写轻微动作（站立、行走、抬头、低头、发呆、静止）
- 【表演模式】：可写大幅度动作、情绪爆发、肢体表演

【旁白拆分规则（仅当旁白过长时）】
- 优先保持完整：一整段旁白尽量放在一个分镜中
- 合理拆分点：如果旁白预估时长 > 10 秒，可按以下位置拆分：
  ✅ 段落结尾（自然分段）
  ✅ 句号结尾（完整语义）
  ✅ 场景转换（时间/地点变化）
  ❌ 不在逗号中间拆分
  ❌ 不在句子中间拆分
- 拆分后每个分镜 8-10 秒，确保旁白语义完整

【重要优先级说明】
- 本 VO 短剧分镜铁则优先于其他任何分镜要求
- 如遇冲突，以本铁则为准

【禁止行为】
- ❌ 禁止旁白存在时，让人物开口说台词/吼叫/对话
```

#### 修改 C：根据 drama_mode 调整"特别要求"

将"特别要求"部分改为根据模式动态变化：

| 模式 | "特别要求"内容 |
|-----|---------------|
| VO主导模式 | "按语义段落完整拆解，保持旁白流畅" |
| 对话主导模式 | "逐句逐段转换为分镜，每句对话优先成镜" |
| 混合模式 | "逐句逐段转换为分镜"（保持原样） |
| 动作/视觉模式 | "按动作场景转换为分镜" |

- ✅ 使用【旁白段】标注
