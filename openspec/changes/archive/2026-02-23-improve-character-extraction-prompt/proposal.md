# 改进角色提取提示词的剧情背景匹配

## 问题背景

在 `GetCharacterExtractionPromptTest` 方法中，当前的风格前缀是固定格式：
```
{{ $('Profiler').first().json.story_artistic_style }}, full body portrait, white background.
```

这种固定格式无法根据剧情背景动态调整角色/道具的风格，导致生成的内容不符合剧本设定：
- 服装不符合剧情时代（如中国古代剧情出现西方服饰）
- 文化风格不匹配（如东方剧情出现西方皇冠）
- 角色外观不符合身份（如帝王角色没有帝王气质）

## 解决方案

采用**方案一 + 方案三**的组合方案：

### 方案三：短期方案 - 支持传入上下文
- 修改 `GetCharacterExtractionPromptTest` 方法签名，添加 `context` 参数
- 在风格前缀中插入剧情背景限定词
- 保持现有功能的同时增强针对性

### 方案一：长期方案 - 自动分析剧本
- 在方法内部添加剧本内容分析逻辑
- 自动提取时代背景（古代/现代/未来）
- 自动识别文化风格（中国风/西方风/日本风）
- 动态生成剧情背景限定词

## 变更范围

- 修改 `GetCharacterExtractionPromptTest` 方法
- 增强 `prompt_i18n.go` 的功能
- 可能需要调整调用方代码

## 预期效果

- 角色外观、服饰、道具风格与剧情背景高度匹配
- 保持功能的通用性和灵活性
- 支持手动传入上下文或自动分析剧本

## 风险评估

- 方法签名变更可能影响现有调用
- 自动分析功能可能需要调整文本处理逻辑
